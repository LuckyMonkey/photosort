# Archive notes

`legacy-photosort/` is the complete tracked snapshot from commit `c1a0499` of `LuckyMonkey/photosort` before PhotoSweep integration. Git history remains available, while this directory makes the old PHP/EXIF keyboard sorter visible in the new project.

The OCR and face-detection notes here are copied from the local implementation audit. They document existing behavior and are not claims that those machine-local dependencies are bundled in this repository.
